# AtomS3 드립커피 추출 타이머

M5Stack AtomS3에 올리는 드립커피 추출 레시피 타이머 펌웨어입니다.
레시피는 WiFi 웹페이지에서 편집하고, 장치에서 측면 버튼으로 고른 뒤 액정을 눌러 시작합니다.

## 동작 흐름

1. **레시피 선택** — 측면(외부) 버튼을 누를 때마다 다음 레시피로 넘어가고 화면에 이름이 표시됩니다.
2. **결정** — 액정(전면 화면)을 누르면 레시피 이름이 **두 번 깜빡**입니다.
3. **시작** — 한 번 더 누르면 해당 레시피가 시작됩니다.
4. **물량 노출** — 각 단계 시작 시 목표 물량(g)이 **3초간** 크게 표시됩니다. (물량이 0이면 생략하고 바로 카운트다운)
5. **추출 진행** — 3초가 지나면 각 단계의 정해진 초를 카운트다운합니다.
   - **5초 남으면 경고 비프**가 울리고, 마지막 4초는 매초 짧은 틱이 울립니다.
   - 카운트다운이 0이 되면 전환 비프와 함께 **자동으로 다음 단계**로 넘어갑니다.
6. **완료** — 마지막 단계가 끝나면 "완료" 화면. 액정을 누르면 선택 화면으로 돌아갑니다.

추출 중 측면 버튼을 누르면 취소되고 선택 화면으로 돌아갑니다.

## 필요한 것

### 보드 / 라이브러리 (Arduino IDE)

- 보드 매니저: **M5Stack** 패키지 설치 → 보드에서 **M5AtomS3** 선택
- 라이브러리 매니저:
  - **M5Unified**
  - **ArduinoJson** (v7 권장)

### 배선

AtomS3에는 내장 부저가 없고, 측면 버튼은 리셋(EN)에 연결되어 소프트웨어 입력으로 쓸 수 없습니다.
그래서 **부저와 레시피 선택 버튼은 외부로 연결**합니다. (핀은 `.ino` 상단 상수에서 변경 가능)

| 부품 | AtomS3 핀 | 연결 |
|------|-----------|------|
| 레시피 선택 버튼 | `G39` (`PIN_SIDE_BUTTON`) | 버튼 한쪽 → G39, 다른쪽 → GND (내부 풀업 사용) |
| 부저 | `G38` (`PIN_BUZZER`) | 부저 + → G38, 부저 − → GND |

- 부저는 **패시브 피에조 부저**가 기본입니다(주파수 구동).
- **액티브 부저**(전압만 주면 소리 나는 모듈)를 쓰면 `.ino`에서 `#define BUZZER_ACTIVE 1` 로 변경하세요.
- "액정 누름"은 AtomS3 전면 화면 버튼(G41)을 그대로 사용하므로 추가 배선이 필요 없습니다.

> G38/G39는 AtomS3 하단 헤더에 노출된 GPIO입니다. 다른 핀을 쓰려면 `.ino` 상단의
> `PIN_SIDE_BUTTON`, `PIN_BUZZER` 값만 바꾸면 됩니다.

## 설정 및 업로드

1. `atoms3_drip_timer.ino` 상단의 WiFi 정보가 집 WiFi로 설정되어 있는지 확인합니다.
   (현재 `U+NetCB90` 으로 설정되어 있음. 바꾸려면 `WIFI_SSID` / `WIFI_PASS` 수정)
   ```cpp
   const char* WIFI_SSID = "U+NetCB90";
   const char* WIFI_PASS = "DD883PDF@0";
   ```
2. Arduino IDE에서 보드 **M5AtomS3**, 올바른 포트를 선택하고 업로드합니다.
3. 부팅 시 "WiFi 연결중..." 후, 화면 하단에 접속 주소(IP)가 표시됩니다.
   - 집 WiFi 접속 성공 → 해당 IP 표시 (예: `192.168.0.42`)
   - 접속 실패 시 자동으로 **AP 모드**로 전환 (`AP:192.168.4.1`).
     폰/PC에서 WiFi `AtomS3-Drip`(비밀번호 `dripcoffee`)에 접속 후 `http://192.168.4.1`

## 레시피 편집 (웹페이지)

- 브라우저에서 **`http://atoms3-drip.local`** 또는 화면에 표시된 **IP 주소**로 접속합니다.
  (mDNS 미지원 환경이면 IP로 접속하세요.)
- 레시피 추가/삭제, 단계별 **라벨 · 물량(g) · 시간(초)** 편집이 가능합니다.
  물량은 단계 시작 시 3초간 표시됩니다. 0으로 두면 해당 단계는 물량 화면을 건너뜁니다.
- **"장치에 저장"** 을 누르면 즉시 장치에 반영되고, 전원을 꺼도 유지됩니다(NVS 저장).

기본 레시피로 **V60 4:6** 과 **기본 핸드드립** 두 가지가 들어 있습니다.

## API (참고)

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/` | 레시피 편집 웹페이지 |
| GET | `/api/recipes` | 현재 레시피 JSON 반환 |
| POST | `/api/recipes` | 레시피 JSON 저장 |

레시피 JSON 형식:
```json
{
  "recipes": [
    {
      "name": "V60 4:6",
      "steps": [
        { "label": "1차", "water": 50, "seconds": 45 },
        { "label": "2차", "water": 70, "seconds": 45 }
      ]
    }
  ]
}
```

최대 레시피 12개, 단계 16개까지 지원합니다.
